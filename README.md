# dragon-pet

Dragon Pet: общий дракон Игнис для компании. Сытость, силы и настроение со временем падают; кормить, катать, гладить и укладывать спать может каждый в чате.

## Запуск

Игра работает совместно только в shapes.inc (через `window.shapes.shared`). Файл `dragon-pet.html` открывается и в браузере, но без общего состояния.
